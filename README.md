Cafetería - Sistema de Cobro
Descripción
Programa en Java que facilita el proceso de cobro en una cafetería aplicando descuentos según el combo seleccionado por el cliente. El sistema calcula automáticamente el descuento correspondiente y muestra el total a pagar, permitiendo realizar el cobro de forma rápida y precisa.
¿Qué problema resuelve?
Este programa evita errores en el cálculo manual de descuentos y totales, agilizando el proceso de atención al cliente y garantizando resultados más precisos durante el cobro.
Funcionalidades
•	Solicita al usuario el tipo de combo seleccionado.
•	Calcula automáticamente el descuento correspondiente.
•	Determina el monto final a pagar.
•	Muestra el resultado en pantalla.
Tecnologías utilizadas
•	Java
•	Programación orientada a consola
•	Proyecto realizado para la materia de Programación - UTP
Instalación y ejecución
1.	Clonar el repositorio.
2.	Ingresar a la carpeta del proyecto.
3.	Compilar el programa con el comando:
javac NombreDelArchivo.java (Cafeteria.java)
1.	Ejecutar el programa con el comando:
   
java NombreDelArchivo.
1.	Seleccionar el combo solicitado por el sistema.
2.	Ingresar los datos requeridos.
3.	Visualizar el descuento aplicado y el total a pagar.
