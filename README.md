
# Cafetería - Sistema de Cobro ☕

Programa en Java que facilita el cobro en una cafetería aplicando descuentos según el combo seleccionado.

### Funcionalidad
- Solicita el tipo de combo
- Calcula el descuento
- Muestra el total a pagar

### Tecnología
- Java
- Realizado para la materia de Programación - UTP
