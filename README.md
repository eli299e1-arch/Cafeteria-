# Cafetería - Sistema de Cobro

Programa en Java que facilita el cobro en una cafetería aplicando
descuentos según el combo seleccionado.

## ¿Qué problema resuelve?
Evita errores al calcular a mano el total de una cuenta cuando hay
descuentos distintos por combo, y agiliza el cobro al cliente.

## Funcionalidad
- Solicita el tipo de combo
- Calcula el descuento
- Muestra el total a pagar
